# 電馭叛客 2077 與《自由幻局》全任務推進與分歧路線圖 (Cyberpunk 2077 Quest & Branching Tracker)

專為《電馭叛客 2077》（Cyberpunk 2077，含資料片《自由幻局 Phantom Liberty》）玩家設計的任務推進與路線決策系統。提供清晰的主線、核心角色支線全景圖，動態推導互斥分支與隱藏結局達成條件，並內建防劇透保護模式。

---

## 關鍵決策審閱 (User Review & Critical Decisions)

> [!IMPORTANT]
> 依據前期討論與您的偏好設定，本規劃確立以下核心規範：

- **雙重視角架構 (Dual-View Matrix)**：
  - **視角 A：互動流程樹狀圖 (Interactive Flowchart Tree)**：可平移（Pan）、縮放（Zoom）、點選節點的高自由度全景圖，以連線標註前後置任務、平行主線與互斥決策。
  - **視角 B：階層式任務檢核表 (Structured Task Checklist)**：以「序章、第一幕、第二幕各主線軸、自由幻局、終局天台、重要支線」分類的直覺勾選清單，適合邊玩邊標記。
- **分支推導與互斥路線計算 (Branching & Mutually Exclusive Logic)**：
  - 勾選特定抉擇（例如《自由幻局》火線交鋒/審判日選擇協助李德或頌鳥、油田墓地關鍵對話）時，系統自動標記解鎖路線、鎖定互斥任務，並即時計算目前已達成的結局可能性。
- **分級防劇透保護機制 (Spoiler Shield Toggle)**：
  - 預設開啟安全模式：隱藏重大劇情轉折與結局衝擊描述；點擊「查看分歧細節」或關閉全域防劇透後，才顯示確切對話選項、關鍵抉擇與不朽裝備/角色生死後果。
- **本地無縫保存 (Persistence)**：
  - 進度即時自動保存於瀏覽器 `localStorage`，並提供多存檔槽位切換與 JSON 匯出/匯入功能。

## 1. 任務收錄全景與分支焦點 (Content Scope & Branching Points)

本推進表收錄全遊戲核心脈絡，並以高識別度標記所有關鍵分岔點：

### A. 本篇主線任務脈絡 (Main Storylines)
1. **序章 (Prologue)**：
   - 3 大出身分支（浪人 Nomad / 街頭混混 Street Kid / 企業人士 Corpo）
   - 救援行動、全食品廠交易《挑撥離間》（多種軍武科技/漩渦幫分歧與多把不朽武器解鎖）
   - 《偷天換日》（The Heist，生死分水嶺、紺碧大廈逃脫路線）
2. **第一幕與第二幕 (Act 1 & 2) 四大平行軸線**：
   - **艾芙琳 / 茱蒂線**：《尋找自我》→《災難》→《雙面間諜》
   - **竹村 / 荒坂線**：《死者蘇生》→《刺客的追尋》→《虎口拔牙》→《臨終祈禱》（**重大分歧點**：竹村生死救助抉擇，影響最終惡魔結局成就）
   - **赫曼 / 帕娜線**：《幽靈鎮》→《閃電突破》→《人生交叉路》（解鎖阿德卡多家族資源）
   - **巫毒幫 / 太平洋線**：《自然發酵》→《勇闖電玩城》→《永不消逝》（**重大分歧點**：網路看守 NetWatch 代理人 vs 莫曼結盟抉擇）
3. **第三幕與終局無退路點 (Point of No Return)**：
   - 《夜曲 Op.55 N.1》迷霧之屋進入天台。
   - **天台決定命運的關鍵對話**：
     - **惡魔結局 (The Devil)**：信任荒坂華子
     - **星星結局 (The Star)**：求助帕娜與阿德卡多
     - **太陽結局 (The Sun)**：求助羅格
     - **節制結局 (Temperance)**：將身體留給強尼·銀手
     - **別怕死神 (Don't Fear The Reaper - 隱藏結局)**：滿足油田墓地 70% 關鍵友好度對話，天台靜默 5 分鐘單挑荒坂塔
     - **自殺走向**：拋棄藥丸，直接落幕

### B. 資料片《自由幻局》(Phantom Liberty Expansion)
1. **狗鎮序幕與特務行動**：《闖入者》→《總統大逃亡》→《黑玉密使》→《黑街暗潮》
2. **審判日關鍵大分岔 (Firestarter / Decision Point)**：
   - **路線 1：協助百合子 / 頌鳥 (Songbird Path)**：
     - 《逃避現實》→《向黑夜前行》（航天港決戰，最終送往月球或交付李德）
     - 解鎖結局：**「杖之王」**（送上太空）或**「劍之王」**（最後反悔交給李德）
   - **路線 2：協助李德 (Solomon Reed Path)**：
     - 《黑之幕》→《消逝的靈魂》（辛諾蘇爾地堡恐怖逃生、決定頌鳥生死）
     - 解鎖結局：**「杯之王」**（安樂死頌鳥）或**「星之王」**（活著引渡給新美國）
3. **DLC 新增本篇主線世界結局**：
   - **塔樓結局 (The Tower)**：治癒 Relic 但淪為平民，告別夜之城傳奇

### C. 關鍵角色重要支線 (Key Companions & Romance)
- **茱蒂·阿爾瓦雷茲**：《艾芙琳悲歌》→《外派任務》→《金字塔之歌》（女 V 專屬浪漫與同居）
- **帕娜·龐默**：《風暴狂襲》→《向公路致敬》→《戰士之歌》（男 V 專屬浪漫、阿德卡多全家族同盟結局必備）
- **瑞 diver 瑞斯**：《獵殺》（河邊兇手救援）→《跟隨我的腳步》（女 V 專屬浪漫）
- **凱瑞·歐羅丁**：《反叛反叛》→《水上划舟》（男 V 專屬浪漫）
- **強尼·銀手羈絆線**：《插管》（Chippin' In，取得保時捷 911、手槍，油田墓地 3 句關鍵對白校對器）→《熾熱戀情》

- **視角 A：流程圖模式 (Flowchart Canvas)**：
  - 支援平移與縮放（Pan & Zoom），以節點卡片清楚呈現前置依賴關係。
  - 特殊警示邊框與分岔標誌：金色節點標示「重大分歧點」、紅色節點標示「互斥/生死影響」、鑽石節點標示「無退路點 (PONR)」。
  - 點擊任一任務節點：右側滑出「任務詳細資訊抽屜（Mission Intel Drawer）」，包含任務簡介、前置條件、關鍵抉擇點、不朽武器掉落與觸發支線。
- **視角 B：清單檢核模式 (Checklist Mode)**：
  - 以章節分群（Prologue / Act 1 / Act 2 / Phantom Liberty / Act 3 & Endings / Major Sidequests）。
  - 單擊勾選完成，可即時過濾「已完成 / 進行中 / 互斥失效 / 隱藏條件尚未滿足」。
  - 支援關鍵字搜尋（例如輸入「竹村」或「不朽」立即高亮相關任務）。
- **結局模擬器與決策看板 (Ending Evaluator)**：
  - 獨立側邊/底部儀表板，實時計算目前勾選的任務狀態，指出已達成的結局條件（例如：「強尼友好度 70% 墓地對白已校準，天台解鎖《別怕死神》」；「救出竹村，惡魔結局解鎖《惡魔》獎盃條件」）。

## 3. 系統架構與技術策略 (Technical Strategy)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        React 19 + TypeScript                            │
│                                                                         │
│  ┌───────────────────────┐   ┌────────────────────────────────────────┐ │
│  │ State Management      │   │ Views & Components                     │ │
│  │ - questStore (State)  │──►│ - TopNav (Status, Filters, Spoilers)   │ │
│  │ - progressStorage     │   │ - FlowchartCanvas (SVG / Node Graph)   │ │
│  │ - branchEngine        │   │ - ChecklistView (Accordion Chapters)   │ │
│  │   (calculates mutual  │   │ - MissionDrawer (Branch Details & Tips)│ │
│  │    exclusions &       │   │ - EndingSummaryModal (Endings status)  │ │
│  │    ending paths)      │   │ - SaveSlotManager (Export/Import JSON) │ │
│  └───────────────────────┘   └────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────┘
```

1. **靜態資料驅動 (Static Mission Graph Data)**：
   - 建立嚴密 typed 的 JSON/TS 資料結構，涵蓋：
     - `id`: 任務代碼
     - `title`: 任務名稱（中英對照，如《偷天換日 The Heist》）
     - `category`: `prologue` | `act1` | `act2_arasaka` | `act2_judy` | `act2_panam` | `act2_voodoo` | `phantom_liberty` | `act3_endings` | `major_side`
     - `isBranchPoint`: 是否為關鍵分岔點
     - `isPointOfNoReturn`: 是否為夜曲無退路點
     - `prerequisites`: 前置任務 ID 陣列
     - `choices`: 分支選擇列表（包含選項內容、導向後續任務、互斥鎖定任務、解鎖結局代碼、隱藏條件提示）
     - `rewards`: 重要報酬（如不朽武器、座車）
     - `spoilerNotes`: 詳細劇情劇透與後續影響描述
2. **分支推理引擎 (Branch Resolution Engine)**：
   - 當使用者標記某抉擇（如選擇背叛頌鳥協助李德），自動將互斥任務狀態變更為 `locked_out`（已鎖定/路線關閉），並在圖表中以虛線及灰色呈現，避免混淆。
3. **無依賴輕量圖形渲染 (Pure SVG / Canvas React View)**：
   - 運用 React + SVG 結合貝茲曲線連線（Bezier curves），無需龐大肥厚的外部重量級圖形函式庫，確保流暢平移、縮放與 60fps 動畫響應。
